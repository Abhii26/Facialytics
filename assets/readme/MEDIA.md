# README media provenance

All application screenshots were captured from **https://facialytics.vercel.app/** on 29 October 2026, displaying **STUDIO / 02.4**.

- Repository: https://github.com/Abhii26/Facialytics
- Reviewed source commit: `dc5c24aafa41484a9e56627ef022e7ac514e52aa`
- Capture browser: Chromium 153.0.8010.0
- Image-analysis input: the application's own bundled Abhishek reference photo.
- Live replay: the same bundled photo was moved through a synthetic 640 × 480, 30 FPS MediaStream. The deployed application's inference, matching, landmark drawing, controls and result cards ran normally. This was not a physical webcam recording or a recognition-accuracy evaluation.
- GIF: 48 captured browser frames encoded at 5 FPS and 960 pixels wide, looping. Displayed application measurements belong to that test environment; the GIF playback rate is not the camera or inference frame rate.
- `hero.svg`: decorative code-native artwork in the application's visual palette; not model output.
- Screenshots are unmodified UI captures; no result values were edited into the images.
- Existing legacy screenshots remain outside this package. The new README references only this `assets/readme/` directory.
